# 135 网页结构：当前站点

> 原件：`../135-网页结构.md`。本副本以当前源码中的 `templates/`、`static/js/`、`engine/` 和 2026-09-17 的域名验证为依据。见 [[130-阅读说明]]。

## 访问入口与页面

| 入口 | 页面结构 | 2026-09-17 验证 |
| --- | --- | --- |
| `https://smrtwatering.com/` | 公共单页应用，侧栏导航到首页、产品介绍、个性化库编译、硬件情况查看 | HTTPS 页面显示正常 |
| `https://www.smrtwatering.com/` | Render 跳转到主域名 | 跳转成功 |
| `https://admin.smrtwatering.com/` | 独立管理页面，先显示管理员密钥登录表单 | 密钥表单显示；未登录后逐项验收 |

上述三个自定义域名均在 Render 显示 `Verified` 与 `Certificate Issued`。主域名与管理子域名使用同一个 Render Web Service；Flask 根据 Host 决定 `GET /` 返回 `templates/index.html` 或 `templates/admin.html`。

## 公共网页四个视图

1. **首页**：产品和硬件介绍、快捷入口、连接状态。
2. **产品介绍**：设备工作方式、模式和使用说明。
3. **个性化库编译**：植物与地点选择、环境信息、栽培和供水表单、配置生成与结果、导入导出。
4. **硬件情况查看**：连接后读取设备状态、历史、配置，并提供需要用户操作的设备控制。未连接时展示连接指引；模拟模式与实体设备必须区分。

`templates/index.html` 提供页面骨架，`static/js/app.js` 管理导航和内存状态，`static/js/pages/` 分拆四个视图。`static/js/services/api.js` 处理 Flask API，`ble.js` 与 `protocol.js` 处理 Web Bluetooth 和 SWS-BLE，`demo.js` 提供模拟设备。页面样式在 `static/css/`。这些是代码结构陈述，不表示每个交互已在生产域名测试。

## 管理页面

`templates/admin.html` 与 `static/js/admin-app.js` 构成独立管理端。管理员输入密钥后，按当前代码可请求健康状态、进程统计、维护日志、植物库和公式。`APP_PROFILE=preview` 时不提供植物修改或 Git 快照操作；后端同时拒绝对应写请求。Cloudflare Access 的第二层登录尚未启用。

## 当前后端结构

- `app.py`：Flask 路由、SQLite 初始化、管理 Host 与密钥校验、系统监控。
- `engine/rules.py`、`engine/validation.py`：场景推导与配置校验。
- `engine/location_catalog.py`、`engine/geocoding.py`、`engine/environment.py`：地点列表、地理匹配与天气服务。
- `knowledge_base/`：全新数据库初始化时使用的植物与计算系数 JSON 种子。

当前网页不以“创建项目 → 保存场景 → 生成 Arduino 代码 → 保存代码版本 → 云端同步设备”为页面主流程。这是原笔记中更早的结构设想，不应在演示时当作已上线功能介绍。

## 页面与源码更新的同步规则

修改页面或导航时同步本篇；改 API 时同步 [[133-API服务-2026上线副本]]；改 BLE 配置格式时同步 [[132-协议使用-2026上线副本]]；改持久化或部署限制时同步 [[136-限制与边界-2026上线副本]]。公网改动需在 Render 新部署后复核主域名和管理域名。
