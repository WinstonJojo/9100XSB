# 133 API 服务：当前 Flask 路由

> 原件：`../133-API服务.md`。本表按当前部署源码的 `app.py` 与 `docs/api.md` 更新；它说明代码定义的接口，不代表各接口都已在公网逐项实测。依据见 [[130-阅读说明]]。

## 公共页面与系统接口

| 方法 | 路径 | 当前作用 |
| --- | --- | --- |
| GET | `/` | 普通 Host 返回公共 HTML；`ADMIN_HOSTS` 中的 Host 返回独立管理 HTML |
| GET | `/healthz` | 无需登录，检查 SQLite 与初始知识库；就绪返回 200，否则 503 |
| GET | `/api/settings` | 公开协议版本、演示状态、能力字段与 BLE UUID；不返回管理员密钥 |
| GET | `/api/plants` | 读取数据库中的植物知识库 |
| GET | `/api/locations/countries` | 经后端获取外部国家/地区列表 |
| POST | `/api/locations/children` | 以已签名的父级令牌获取省份/城市或海外主要城市 |
| POST | `/api/locations/select` | 确认终点城市，返回地点与 `locationToken` |
| POST | `/api/environment`、`/api/locations/environment` | 按已确认地点令牌查询实时 API 天气 |
| POST | `/api/configurations/generate` | 校验场景、重新取环境数据并生成配置与解释 |
| POST | `/api/configurations/import` | 校验导入配置和可选当前 revision |
| POST | `/api/configurations/export` | 输出 JSON 配置文件 |

兼容或退役路径：`GET /api/locations` 返回空列表并说明地点只来自外部；旧式 `GET /api/weather`、`GET /api/environment` 与 `POST /api/locations/resolve` 返回 410，提示改用地点令牌流程。

## 管理接口

所有 `/api/admin/*` 路由同时要求管理域名 Host 和 `Authorization: Bearer <ADMIN_TOKEN>`；普通域名或密钥错误不会放行。

| 方法 | 路径 | 当前作用与 preview 行为 |
| --- | --- | --- |
| GET | `/api/admin/health` | 数据库、运行时间、知识库版本 |
| GET | `/api/admin/stats` | 当前进程请求、错误、生成数及平均耗时 |
| GET | `/api/admin/logs` | 维护日志，`limit` 最多 100 |
| GET | `/api/admin/formulas` | 计算公式与当前系数，只读 |
| GET | `/api/admin/libraries/plants` | 读取数据库植物库 |
| PUT | `/api/admin/libraries/plants` | standard 可更新；当前 preview 返回 403 `preview_read_only` |
| GET | `/api/admin/git/status` | preview 返回“未启用”，不调用 Git |
| POST | `/api/admin/git/snapshot` | standard 在具备 Git 环境时可尝试提交；当前 preview 返回 403 |

## 数据来源与错误

SQLite 目前存储植物、计算系数和系统维护日志；不创建旧笔记中的 `projects`、`scenarios`、`parameters`、`code_versions`、`device_sync_log` 等业务表。地点列表及天气来自外部服务，后端不把它们作为内部地点库长期保存。天气或地点服务失败会报错，不能把无数据当成成功配置生成。

API JSON 使用 camelCase。错误通常包含 `status`、`message`，可有 `field`、`code`。POST 需要 `application/json`，请求体上限 64 KB，API 响应禁止缓存。具体字段和最新规则以部署源码 `docs/api.md` 为准。

## 旧接口的处理

原笔记中的 `/api/project`、`/api/project/<id>/generate`、`/api/device/<id>/config`、`/api/device/register` 等**不在当前 Flask 路由表中**，不能供当前前端或设备直接调用。ESP32 固件上的 SoftAP HTTP 接口也不属于 Render 服务器；需在设备固件源码中另行核对。
